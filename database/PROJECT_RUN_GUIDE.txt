================================================================================
                     CAREER CREDENTIALS - PROJECT RUN GUIDE
================================================================================
                     Complete Terminal Commands & Setup Instructions
================================================================================

This guide provides ALL commands needed to run the Career Credentials project
with all its components (Frontend, Backend, Admin Backend, AI Backend, Resume Builder).

================================================================================
PART 1: PREREQUISITES
================================================================================

Before running, ensure you have:
  ✅ Node.js v18+ installed
  ✅ Java JDK 17+ installed
  ✅ Maven installed
  ✅ MySQL running on port 3306
  ✅ MongoDB running on port 27017
  ✅ .NET SDK 6+ installed (for Resume Builder)

================================================================================
PART 2: DATABASE SETUP
================================================================================

MYSQL (Port 3306):
  Database: career_guidance
  
  Tables Required:
    - students
    - student_feedback
    - recorded_sessions
    - admins

MONGODB (Port 27017):
  Database: career_guidance
  
  Collections Required:
    - students
    - meetings
    - sessions
    - subjects

PART 7: TROUBLESHOOTING
================================================================================

ISSUE: Port already in use
  SOLUTION: Kill existing process or change port in config

ISSUE: npm start fails
  SOLUTION: Delete node_modules and run npm install again

ISSUE: Maven build fails
  SOLUTION: Run mvn clean install -DskipTests

ISSUE: MySQL connection error
  SOLUTION: Verify MySQL is running and credentials in application.properties

ISSUE: MongoDB connection error
  SOLUTION: Verify MongoDB is running on port 27017

ISSUE: Feedback carousel not showing
  SOLUTION: Ensure Admin Backend (8081) is running and has feedback data

PART 9: TRAINER REGISTRATION & LOGIN
================================================================================

The Trainer panel is separate from Admin and Student. Trainers can:
  - View pending retest requests
  - Approve or reject retest requests
  - Manage student career assessments

------------------------------------------------------------------------------
STEP 1: ENSURE ADMIN BACKEND IS RUNNING
------------------------------------------------------------------------------
  cd D:\Cdac\Career-Portal1\Admin\backend
  mvn spring-boot:run

  Wait for: "Started AdminApplication" in terminal output

------------------------------------------------------------------------------
STEP 2: REGISTER TRAINER (admin1) - Using PowerShell
------------------------------------------------------------------------------
  Open a NEW PowerShell terminal and run:

  Invoke-RestMethod -Method Post -Uri "http://localhost:8081/api/trainer/register" -ContentType "application/json" -Body '{"fullName":"admin1","email":"admin1@credentials.com","password":"Admin@123","specialization":"Career Counseling"}'

  EXPECTED RESPONSE:
  {
    "success": true,
    "message": "Trainer registered successfully"
  }

------------------------------------------------------------------------------
STEP 2 (ALTERNATIVE): REGISTER TRAINER - Using MySQL Directly
------------------------------------------------------------------------------
  Open MySQL Workbench or command line and run:

  INSERT INTO trainer (full_name, email, password_hash, specialization, status, created_at) 
  VALUES (
      'admin1',
      'admin1@credentials.com',
      '$2a$10$N9qo8uLOickgx2ZMRZoMyeIjZAgcfl7p92ldGxad68LJZdL17lhWy',
      'Career Counseling',

  );

  NOTE: The password_hash above is BCrypt hash of "Admin@123"

------------------------------------------------------------------------------
STEP 2 (ALTERNATIVE): REGISTER TRAINER - Using Postman
------------------------------------------------------------------------------
  1. Open Postman (download from https://www.postman.com/downloads/)
  2. Create new request:
     - Method: POST
     - URL: http://localhost:8081/api/trainer/register
     - Body → Raw → JSON:
       {
         "fullName": "admin1",
         "email": "admin1@credentials.com",
         "password": "Admin@123",
         "specialization": "Career Counseling"
       }
  3. Click "Send"
